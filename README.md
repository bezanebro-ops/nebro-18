# እቴነሽ ጌታው ፋሽን ዲዛይን — የንግድ አስተዳደር ስርዓት

ይህ የመነሻ ስሪት የዳታቤዝ (Database)፣ የንግድ ህጎች (Business Rules)፣ ዳሽቦርድ (Dashboard)፣ ደንበኞች እና ትዕዛዞች መሠረት ይዟል።

## ቋንቋ
የተጠቃሚ ገጽታ አማርኛ ነው። የቴክኒክ ቃላት በቅንፍ ውስጥ በእንግሊዝኛ ይከተላሉ።
የሚታየው ቀን በኢትዮጵያ ዘመን መቁጠሪያ (Ethiopian Calendar) ይሆናል።

## ማስጀመሪያ
1. Python 3.11+ ይጫኑ።
2. Terminal/CMD ይክፈቱ።
3. `pip install -r requirements.txt`
4. `streamlit run app/main.py`

## ዋና መርህ
መረጃ አንድ ጊዜ ብቻ ይመዘገባል። የገንዘብ መዝገቦች በቀጥታ አይሰረዙም፤ በመሻር (Void) ሂደት ይቆጠራሉ።
